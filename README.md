# dubCal

Windows 바탕화면에 붙여 사용하는 Rust 월간 달력 위젯입니다. 기본 Google 캘린더를 조회하고 날짜를 더블클릭해 일정을 추가할 수 있습니다. 일정 제목을 더블클릭하면 날짜·시간과 상세 정보를 수정하거나 삭제할 수 있습니다. 반복 일정은 표시하며 편집은 Google Calendar에서 합니다.

제목 표시줄과 작업 표시줄 항목 없이 Explorer 바탕화면의 자식 창으로 연결합니다. 일반 앱 창이 위젯 위에 표시되며, Win+D로 바탕화면을 표시할 때도 달력을 사용할 수 있도록 구현했습니다. 위젯 영역에 겹치는 바탕화면 아이콘은 가려집니다.

- **Alt + 마우스 왼쪽 버튼**으로 달력 안쪽을 드래그해 위치를 옮깁니다.
- 이동 중 모니터 작업 영역 가장자리의 16 논리 픽셀 안으로 접근하면 붙습니다. 모서리에서는 가로·세로가 함께 붙으며, 다시 안쪽으로 드래그하면 떨어집니다. 작업 표시줄 영역은 제외합니다.
- **오른쪽 아래 모서리의 손잡이**를 마우스 왼쪽 버튼으로 드래그해 크기를 조절합니다.
- 이동·크기 조절을 마치면 위치와 크기를 자동 저장하고 다음 실행에서 복원합니다. 화면 배치가 바뀌면 현재 모니터 작업 영역 안으로 보정합니다.
- 최소 크기는 700×500 논리 픽셀이며, 모니터 작업 영역이 더 작으면 화면에 맞춥니다.
- 달력에서 **Alt + 우클릭 → 종료**로 위젯을 닫습니다. EXE를 다시 실행하면 표시됩니다.
- Alt + 우클릭 메뉴는 일정 입력 창과 같은 둥근 모서리와 여백, 설명이 있는 카드형 항목으로 표시합니다. 이전 달·이번 달·다음 달을 눌러도 메뉴가 유지되어 연속 이동할 수 있습니다. 메뉴 바깥 클릭이나 Esc로 닫습니다.
- 상단에는 `yyyy년 mm월`만 표시합니다. **Alt + 우클릭** 메뉴에서 이전 달, 다음 달, 이번 달, Google 연결, 새로고침, 설정, 종료를 사용합니다. 날짜/일정 더블클릭 편집은 그대로 사용합니다. 오류와 작업 상태도 메뉴에 표시합니다.
- Explorer의 `SHELLDLL_DefView` 구조를 사용하므로 Windows 버전에 따라 연결이 실패할 수 있습니다. 실패하면 위젯에 오류와 재시도 버튼이 표시됩니다.
- Explorer 재시작 후 위젯이 사라지면 EXE를 다시 실행하세요. Windows 로그인 시 자동 실행은 포함하지 않습니다.

## 일정 입력과 수정

달력 날짜를 더블클릭하면 여백을 둔 입력 창이 열립니다. 입력란을 클릭하면 키보드 포커스를 받아 한글·영문을 입력할 수 있습니다. 백그라운드 일정 조회 중에도 입력할 수 있으며, 저장·삭제를 전송하는 동안만 입력을 잠급니다. 내용은 스크롤하며 입력하고, 저장·취소 버튼은 창 아래에 유지됩니다.

- **제목**, **설명/메모**, **장소/온라인 회의 링크**
- **시작·종료 날짜와 시간**, **종일 일정**: 입력칸 옆 **선택** 버튼으로 날짜 달력이나 시·분 선택기를 엽니다. 날짜를 클릭하면 바로 반영하고, 시간은 시·분을 선택한 뒤 **적용**을 누릅니다. 입력칸에 직접 입력할 수도 있습니다. 날짜는 `YYYY-MM-DD`, 시간은 24시간제 `HH:MM`입니다. 시간은 PC 현지 시간 기준으로 Google에 시간대 오프셋과 함께 저장됩니다. 밤을 넘기거나 여러 날에 걸치는 일정도 지원합니다.
- **일정 색상**: 캘린더 기본색 또는 11개 Google 일정 색상. 달력에도 색상 점으로 표시합니다.
- **공개 범위**: 캘린더 기본 설정, 비공개, 공개
- **일정 상태**: 바쁨 또는 한가함
- **알림**: 캘린더 기본 알림을 사용하거나, 팝업·이메일 알림을 최대 5개 설정합니다. 알림 시점은 시작 전 0~40320분(4주)입니다. 기본 알림을 끄고 항목을 모두 삭제하면 알림이 없는 일정이 됩니다. 알림은 Google Calendar 쪽에서 처리합니다.

기존 일정의 상세 정보와 여러 날에 걸친 기간도 불러옵니다. 종일 일정의 종료 날짜는 마지막으로 포함할 날짜입니다. 입력 오류는 저장 전에 표시하며, 저장 실패 시 창과 입력 내용을 유지합니다. 저장 자체가 완료되고 새로고침만 실패하면 중복 저장을 피하도록 이를 구분합니다.

반복 일정 편집, 참석자 초대, Google Meet 자동 생성, 첨부파일 추가는 Google Calendar에서 사용합니다. 장소란에는 기존 온라인 회의 링크를 넣을 수 있습니다.

[Google Calendar 일정 필드 문서](https://developers.google.com/workspace/calendar/api/v3/reference/events)

## 테마와 투명도

달력 안에서 **Alt + 우클릭 → 설정 · 테마 / 투명도**로 테마와 투명도를 변경합니다.

- 라이트: 페이퍼, 아이보리, 민트, 스카이, 라벤더
- 다크: 미드나이트, 차콜, 포레스트, 오션, 플럼
- 투명도: 0~80%. 0%는 불투명하며 글자와 버튼을 포함한 위젯 전체에 적용됩니다.
- **기본값 복원**은 미드나이트 테마와 투명도 0%로 되돌립니다.
- 시작 시에도 저장된 투명도를 적용하고, 창 초기화 과정에서 속성이 바뀌어도 유지합니다.
- 설정은 `%LOCALAPPDATA%\DeskCalendar\appearance.json`에 자동 저장됩니다.

Windows 10/11용 호환성 매니페스트와 layered child window API를 사용합니다. 실제 Windows에서 투명도 변경 후 달력 클릭, Alt 드래그, 일정 입력 및 재실행 시 설정 복원을 확인해야 합니다.

## 빌드

Windows에 [Rust](https://rustup.rs/)와 Visual Studio Build Tools의 C++ 데스크톱 개발 워크로드를 설치합니다. 프로젝트 폴더에서 다음을 실행합니다.

```powershell
cargo build --release
```

WSL에서 Windows x64로 교차 빌드할 수도 있습니다.

```bash
cargo build --release --target x86_64-pc-windows-gnu --offline
```

결과: `target/x86_64-pc-windows-gnu/release/dubCal.exe`

## Windows 실행 확인

교차 빌드는 Linux에서 수행했습니다. 다음 항목은 실제 Windows에서 확인해야 합니다.

1. EXE 실행 후 제목 표시줄과 작업 표시줄 항목 없이 달력이 보이는지 확인합니다.
2. 메모장 등 일반 앱을 열어 위젯 위에 표시되는지 확인합니다.
3. Win+D를 두 번 눌러도 바탕화면에 위젯이 남는지 확인합니다.
4. Alt + 왼쪽 드래그로 이동하고 오른쪽 아래 손잡이로 크기를 바꾼 뒤, 종료·재실행 시 같은 위치와 크기가 복원되는지 확인합니다.
5. 날짜 더블클릭 후 한글 입력과 저장을 확인합니다.
6. Google 연결과 새로고침, 종료를 확인합니다.

## Google 연결

OAuth 설정을 포함해 빌드한 `dubCal.exe`는 별도 JSON 파일 없이 사용할 수 있습니다. **Alt + 우클릭 → Google 연결**을 선택하고 브라우저에서 로그인·권한 승인을 진행합니다. 토큰은 Windows 자격 증명 관리자에 저장합니다.

연결을 누르면 별도 상태 창이 즉시 표시됩니다. 다른 일정 작업이 진행 중이면 끝난 뒤 로그인을 시작합니다. 브라우저는 Windows 기본 URL 처리기로 실행합니다. 자동 실행이 되지 않으면 **로그인 페이지 열기** 또는 **로그인 링크 복사**를 사용하세요. 링크를 브라우저 주소창에 붙여넣어도 같은 로컬 콜백으로 연결됩니다. 로그인 대기는 3분이며 취소할 수 있습니다. 실패하면 상태 창의 오류를 확인하거나 **오류 내용 복사**로 복사할 수 있습니다.

### 개발자용 OAuth 설정

1. Google Cloud 프로젝트에서 Google Calendar API를 사용 설정합니다.
2. Google Auth Platform에서 동의 화면을 설정합니다. 외부 앱이 테스트 상태라면 사용할 Google 계정을 테스트 사용자에 추가합니다.
3. OAuth 클라이언트를 **데스크톱 앱** 유형으로 만들고 JSON을 내려받습니다.
4. 빌드할 때 파일 경로를 환경 변수로 지정합니다.

```bash
DUBCAL_OAUTH_JSON="/absolute/path/to/desktop-oauth.json" cargo build --release --target x86_64-pc-windows-gnu --offline
```

클라이언트 ID와 클라이언트 보안 비밀번호만 빌드 결과에 포함합니다. 원본 JSON을 소스에 복사하지 않습니다. 환경 변수 없이 빌드하면 EXE 옆 `google-oauth.json`을 읽는 방식으로 동작합니다. 실행 인자로 JSON 경로를 명시하면 포함된 설정보다 해당 파일을 우선합니다.

데스크톱 앱에 포함된 OAuth 클라이언트 정보는 실행 파일에서 추출될 수 있습니다. 사용자 로그인 토큰과 서비스 계정 키를 실행 파일에 포함하지 마세요. 기존 로그인은 같은 클라이언트 ID일 때 유지되며, 클라이언트가 달라지면 다시 연결해야 합니다.

- [Google OAuth 데스크톱 앱 문서](https://developers.google.com/identity/protocols/oauth2/native-app)
- [Calendar API 이벤트 조회 문서](https://developers.google.com/workspace/calendar/api/v3/reference/events/list)
